Provider Page Settings

Provider Page Style

There are two styles of provider profile page available. Admin can choose either of them.

There are two options to redirect user after payment for booking:

  • Redirect on same booking page: User will get redirect to provider profile page after PayPal payment.
  • Thank You page: Admin can define the page url here and user will get redierct to this page after payment.
