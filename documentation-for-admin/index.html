Minimal Requirements

If you’re planning to build a website using WordPress, you must first ensure your hosting provider meets WP’s requirements.

Database

  1. MySQL 5.0 or higher

PHP

  1. PHP 5.2.4 or higher
  2. PHP5 GD library installed
  3. Notices & Warnings are turned off
  4. Enabled mod_rewrite in Apache for clean URLs
  5. Memory limit set up at least 64MB
  6. Upload_max_filesize at least 10MB

Upload the theme zip folder from admin area

  1. Log in to your WordPress admin area.
  2. Browse to Appearance > Themes.
  3. Click on ‘Add New’.
  4. Click ‘Upload’.
  5. Browse and select the theme zip file to ‘Upload’.

Upload Via FTP

  1. WordPress files can also be uploaded manually via FTP.
  2. Upload the files to /wp-content/themes/ folder on your server.
  3. Login to your WordPress admin area to change the theme.
  4. Check out the guide on WordPress.org here.
