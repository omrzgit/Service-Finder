Search Template

There are two styles available for search result page.







Search Page Header Style

Admin can select either to show banner or map in second version of search result page.

There are three sorting criterias available in serach result page:

  • Page reload: If user selects this option then page will reload and show filtered results.
  • Ajax Filter: If user selects this option then then page will show filtered results via ajax call.
  • Ajax with url change: If user selects this option then page will show filtered results via ajax and same time the url of page will also get changed. So filtered results will remain there if going back or forward via browser back and forward button or reloading the page.

Admin can set up the number of resultes to show per page from here.
