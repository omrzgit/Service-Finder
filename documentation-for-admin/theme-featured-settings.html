Featured Settings

Feature Provider

If admin enable this option then featured provider option will be available on website. Admin can define the minimum and maximum number of days available for featured provider. Provider can send request to admin to make them featured. Provider need to select desire number of days from here. Upon submission the request will be sent to admin and admin can find all requests here. Admin can reject the request or approve the request. While approving admin can define the price according to number of days requested and notification will be sent to provider to make the payment in order to get featured.
