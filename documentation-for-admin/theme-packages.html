Packages

Active Packages 1

There are three pre-defined packages available. Admin can enable or disable packages from here.

Admin can set up the capabilities to include in any package. There are six capabilities given:

  • Bookings: This capability will allow provider to have booking option on their profile page. There are few sub capabilities also associated to booking option:
    • Invoice:This capability will allow provider to generate invoice for each booking or for each user.
    • Availability: This capability will allow provider to define available time slots for each day for booking.
    • Staff Member: This capability will allow providers to create staff member and make them available at the time of booking for selection by the cutomer.
  • Cover Image on provider page: This capability will allow provider to upload own cover image on their profile page.
  • Gallery with more image: We have given option to have control over number of images to upload by provider under each package. Admin can also define default number of images to upload under gallery. So default number of images will be available for each provider and if they want to upload more image under gallery then they can select package for more images.
